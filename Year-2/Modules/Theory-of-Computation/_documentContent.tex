\subsection{Finite-State Automata and Regular Languages}

\subsubsection{Formal Definitions}

\definition{Deterministic Finite-State Automaton}{A \underline{deterministic finite-state automaton} is a five-tuple \((Q,\Sigma,\delta,q_0,F)\) where \(Q\) is the finite set of states, \(\Sigma\) is a finite alphabet, \(\delta: Q \times \Sigma \rightarrow Q\) is the transition function, \(q_0 \in Q\) is the start state, and \(F \subseteq Q\) is the set of accept states.}

\separate{7}\definition{Recognises}{A DFA \(M\) recognises the language \(L\) if \(L = \{w | M \text{ accepts } W\}\).}

\separate{7}\definition{Regular Languages}{A language is called a \underline{regular language} if some DFA recognises it.}

\separate{7}\definition{Regular Expression}{A \underline{regular expression} \(R\) defines a language \(L(R)\). We shall eventually prove that \(RE \equiv DFA\). \(R\) is a regular expression over the alphabet \(\Sigma\) if \(R\) is:
\begin{enumerate}
    \item \(a\) for some \(a \in \Sigma\).
    \item \(\epsilon\) (the empty string).
    \item \(\emptyset\) (the empty set).
    \item \((R_1 \cup R_2)\) where \(R_1\) and \(R_2\) are regular expressions.
    \item \(R_1 \cdot R_2\) where \(R_1\) and \(R_2\) are regular expressions.
    \item \(R_1^*\) where \(R_1\) is a regular expression.
\end{enumerate}
The list of regular operations can be seen in \elemref{tab:Regular Operations.}{Table} where the operations labelled with \(^+\) are language theory specific.}

\inserttable{c|c|c}{Regular Operations.}{\textbf{Operation Name} & \textbf{Notation} & \textbf{Set Equivalent}}

\subsubsection{Combining Automata}

Sometimes we may want to implement an operation on multiple languages. We can do this by combining their automata. If we have that \(L_1\) is recognised by \(M_1 = (Q_1,\Sigma,\delta_1,q_1,F_1)\) and \(L_2\) is recognised by \(M_2 = (Q_2,\Sigma,\delta_2,q_2,F_2)\); we want to combine \(M_1\) and \(M_2\) into a new automaton \(M\) that would recognise \(L_1 \cup L_2\).

You would think that we could just run the automata sequentially, and accept if either \(M_1\) or \(M_2\) accept, but this does not work. This is because after \(M_1\) has run on the input, the input is exhausted and there is no way to rewind it in order to run \(M_2\).

Instead, we can attempt to run \(M_1\) and \(M_2\) on the input in parallel. We do this by using pairs of states (one for each DFA). Formally, the components of the new automaton \(M = (Q, \Sigma, \delta, q_0, F)\) are:
\begin{enumerate}
    \item The set of possible states contains every possible cross-set pair of \(Q_1\) and \(Q_2\).
    \[Q = Q_1 \times Q_2\] 
    \item For every \(s \in Q_1, u \in Q_2, a \in \Sigma\). The transition function contains every transition from a pair of states from \(Q\) being given any input from \(\Sigma\).
    \[\delta((s,u),a) = (\delta_1(s,a),\delta(u,a))\]
    \item The start state is the pair containing both start states from \(M_1\) and \(M_2\).
    \[q_0 = (q_1,q_2)\]
    \item The set of accept states is every possible cross-set pair of accept states from \(F_1\) and \(F_2\).
    \[F = \{(s,u) \in Q | s \in F_1 \text{ or } u \in F_2\}\]
\end{enumerate}

\subsubsection{Non-Deterministic Finite Automaton}

If, instead you wish to work with concatenation, such that \(w \in L_1 \circ L_2\) only if there are words \(x\) and \(y\) such that \(w=xy\), \(x \in L_1\) and \(y \in L_2\). You need to run \(M_1\) on a prefix of \(w\) and then run \(M_2\) on the rest. This must be done non-deterministically and stops becoming a DFA as all accept states of \(M_1\) have to map to the start state of \(M_2\).

\separate{7}\definition{Non-Deterministic Finite Automata}{A \underline{non-deterministic finite automaton} is a five-tuple \((Q,\Sigma,\delta,q_0,F)\), where \(Q\) is the finite set of states, \(\Sigma\) is a finite alphabet, \(\delta: Q \times (\Sigma \cup \{\epsilon\}) \rightarrow \mathscr{P}(Q)\) is the transition function, \(q_0 \in Q\) is the start state, and \(F \subseteq Q\) is the set of accept states.}

\subsubsection*{Computing NFA}

Before computing an NFA, an important convention to note is that a single step in a computation consists of first reading the next input symbol followed by taking any number of \(\epsilon\)-transitions. This means that empty strings \(\epsilon\)s can be freely added inside the actual word \(\in \Sigma*\), e.g., 010110 can be viewed as, say, \(\epsilon 01 \epsilon\epsilon 01 \epsilon 01\).

Let \(M = (Q,\Sigma,\delta,q_0,F)\) be an NFA and \(w=w_1w_2...w_n\) be a word over \(\Sigma \cup \{\epsilon\}\). \(M\) accepts \(w\) if there exists a sequence of states \(r_0,r_1,r_2,...,r_n\) satisfying the following conditions:
\begin{enumerate}
    \item \(r_0 = q_0\).
    \item \(r_{i+1} \in \delta(r_i,w_{i+1})\) for every \(i, 0 \leq i \leq n-1\).
    \item \(r_n \in F\).
\end{enumerate}

\subsubsection{Converting NFA into DFA}

The difference between a DFA and NFA is that a DFA has a unique computation (path) and either accepts or rejects, while an NFA generally has many computation paths and accepts if at least one computation accepts and only rejects if all the computations reject.

\separate{7}\theorem{nfa to dfa}{Every NFA has an equivalent DFA.}
{To formally convert an NFA to a DFA, let \(N = (Q, \Sigma, \delta, q_0, F)\) be an NFA recognising some language \(L\) (assume that \(N\) has no \(\epsilon\)-transitions). We shall construct a DFA \(M = (Q', \Sigma, \delta', q_0', F')\) that recognises the same language \(L\) as follows.
\begin{enumerate}
    \item \(Q' = \mathscr{P}(Q)\).
    \item For \(R \in Q'\) and \(a \in \Sigma\), let
    \begin{equation}\label{equation:step2a}
        \delta'(R,a) = \{q \in Q | q \in \delta(r,a) \text{ for some } r \in R\}
    \end{equation}
    equivalently,
    \begin{equation}\label{equation:step2b}
        \delta'(R,a) = \bigcup_{r \in R} \delta(r,a)
    \end{equation}
    \item \(q_0' = \{q_0\}\).
    \item \(F' = \{R \in Q' | \exists r \in R, r \in F\}\).
\end{enumerate}
Now, to consider \(\epsilon\)-transitions, for \(R \subseteq Q\), let 
\begin{equation}
    E(R) = \{q | q \text{ is reachable from } R \text{ through a number of } \epsilon \text{-transitions.}\}
\end{equation}
Now, taking the above steps, we modify \eqref{equation:step2a} to
\begin{equation}
    \delta'(R,a) = \{q \in Q | q \in E(\delta(r,a)) \text{ for some } r \in R\}
\end{equation}
and \eqref{equation:step2b} to
\begin{equation}
    \delta'(R,a) = \bigcup_{r \in R} E(\delta(r,a))
\end{equation}
We then modify step 3 to say \(q_0' = E(\{q_0\})\).}

\separate{7}\numberedentry{corollary regex nfa}{Corollary}{A language is regular iff some NFA recognises it.}
\proof{entry:corollary regex nfa}{See \postenvref{thm:nfa to dfa}{Theorem}{theoremnumber}.}

\separate{7}\theorem{regex expression recognition}{A language is regular iff some regular expression describes it.}
{\(\Leftarrow\) Given a regular expression \(R\), construct a NFA that recognises \(L(R)\) by structural induction:
\begin{itemize}
    \item \textit{Base Case}: All initial regular expressions can be implemented by NFAs.
    \item \textit{Inductive Step}: We have already proven that the class of regular languages is closed under regular operations.
\end{itemize}

\noindent \(\Rightarrow\) Given a DFA \(M\), construct a regular expression that recognises \(L(M)\).
\begin{enumerate}
    \item Convert the given \(n\)-state DFA into an equivalent \(n+2\) state GNFA.
    \item Eliminate all the internal states of the GNFA one-by-one, while preserving the language recognised by the automaton.
    \begin{enumerate}
        \item Pick an internal state \(r\) for elimination.
        \item For every two states \(u\) and \(v\) with transitions between them and \(r\), \(u \neq r, v \neq r\), combine the regular expressions of the three into one, new expression.
    \end{enumerate}
    \item \(L(R)\) should now equal \(L(M)\).
\end{enumerate}}

\separate{7}\definition{GNFA}{A \underline{generalised non-deterministic finite automaton} is defined as having a single start state with no incoming edges, a single end state with no outgoing edges, and every transition being labelled with a regular expression.}

\subsubsection{Non-Regular Expression}

\definition{Non-Regular Expressions}{A \underline{non-regular expression} is a language which cannot be recognised by any DFA. We prove a language is non-regular by assuming there is a DFA that recognises language \(L\) and then use an adversary argument against that DFA to get a contradiction.}

\separate{7}\lemma{Pumping Lemma}{The \underline{pumping lemma} states that, for every regular language \(L\), there is a number \(p\) (the pumping length of \(L\)) such that every word \(w \in L\) of length at least \(p\) can be divided into three parts \(w=xyz\), satisfying the following conditions:
\begin{enumerate}
    \item \(xy^iz \in L\) for every \(i \in N\) (in particular \(xz \in L\) as one can take \(i = 0\)).
    \item \(y\) is a non-empty string.
    \item The length of the string \(xy\) is not greater than \(p\).
\end{enumerate}}
{Let \(M = (Q, \Sigma, \delta, q_0, F)\) be a DFA that recognises \(L\), and let us set the pumping length \(p\) to be the number of states in \(M: p=|Q|\). Consider the computation of \(M\) on the word \(w=w_1w_2...w_n\) where \(n \geq p\).
\begin{equation}
    q_0 = r_0 \rightarrow w_1 \rightarrow r_1 \rightarrow w_2 \rightarrow ... r_{n-1} \rightarrow w_n \rightarrow r_n \in F
\end{equation}
Let \(i\) be the first moment in time when we see a repetition in the sequence of states \(r_0,r_1,...,r_n\) (such an \(i\) must exist by the Pigeon-Hole principle, as \(n+1 > p\)). i.e., \(r_i = r_j\) for some \(i > j\) and the states \(r_0,r_1,...,r_{i-1}\) are all different. We can then set
\begin{equation}
    x = w_1w_2...w_j \quad y = w_{j+1}...w_i \quad z = w_{i+1}...w_n
\end{equation}
It is now straightforward to check that all three conditions are met.}

\subsection{Greedy Algorithms}

\definition{The Knapsack Problem}{\underline{The knapsack problem} is defined as one of two variants. Either:
\begin{itemize}
    \item The \underline{0-1 knapsack problem} (the classic variant), where a thief robs a store and finds \(n\) items. Item \(i\) is worth \(v_i\) euros and weighs \(w_i\) kilos. The thief can carry at most \(W\) kilos in his knapsack. \textit{Which items can he take to maximise his profit?}
    \item the \underline{fractional knap problem}, which has the same setup, but this time the thief can take fractions of items.
    \item We can assume (without loss of generality) that the knapsack is not big enough to carry all items:
    \begin{equation}
        W < w_1 + w_2 + ... + w_n
    \end{equation}
\end{itemize}}

\subsubsection{The Greedy Approach}

To solve the fractional problem, the greedy approach would be to calculate the value per kilo using \eqref{equ:knapsack_value} for each item. You then sort the items by value per kilo, in decreasing order. You then take as much of the first item as possible, then the second item, etc., until you reach the capacity of the knapsack \(W\).
\begin{equation}\label{equ:knapsack_value}
    r_i = \frac{v_i}{w_i}
\end{equation}


\separate{7}\example{Greedy knapsack}{For example, if \(W=10\), and \(\mathbf{v} = \{4, 10, 12, 20\}\) and \(\mathbf{w} = \{4, 2, 8, 5\}\). We can then calculate \(\mathbf{r} = \{1, 5, 1.5, 4\}\). The greedy algorithm then dictates that you should take all of item 2, all of item 4, and 3 kilos of item 3 \(W = 2 + 5 + 3\). This gives a total value of \(V = 10 + 20 + (3 \times 1.5) = 34.5\).}

\separate{7}The running time of this algorithm can be calculated by taking that:
\begin{enumerate}
    \item Step 1, calculating the value per kilo takes \(\Theta (n)\).
    \item Step 2, sorting the value per kilo array takes \(\Theta (n\;log\;n)\).
    \item Step 3, selecting the items can be done in \(\Theta (n)\).
\end{enumerate}
Therefore, the worst-case running time is \(\Theta (n\;log\;n)\).

\separate{7}However, approach will not work for the 0-1 knapsack problem.

\subsubsection{Correctness of the Greedy Algorithm for Fractional Knapsack}

\(n\) items are sorted by value per kilo, \eqref{equ:knapsack_value} in decreasing order, i.e., 
\begin{equation}
    r_1 \geq r_2 \geq ... \geq r_n
\end{equation}
Two items, \(p\) and \(q\) with \(r_p = r_q\) are considered to be equivalent. Hence, we may assume that
\begin{equation}
    r_1 > r_2 > ... > r_n
\end{equation}
The total available amount of item \(i\) is \(w_i\). Let \(k\) be such that
\begin{equation}
    w_1 + w_2 + ... + w_k \leq W
\end{equation}
and
\begin{equation}
    w_1 + w_2 + ... + w_{k+1} > W
\end{equation}
Let \(\mathbf{x} = (x_1, x_2, ..., x_n)\) denote a solution: \(0 \leq x_i \leq w_i\) is the amount the thief takes of item \(i\) for \(i = [0, n]\). The total value taken is then given by
\begin{equation}
    \sum_{i=1}^{n} r_ix_i
\end{equation}
The greedy solution \(\mathbf{x}\) is given by \(x_i = w_i\) for \(1 \leq i \leq k\) and 
\begin{equation}
    x_{k+1} = W - (w_1 + w_2 + ... + w_k)
\end{equation}
\(x_i = 0\) for \(k+2 \leq i \leq n\). Let \(\mathbf{x}^* = (x_1^*, x_2^*, ..., x_n^*)\) be an optimal solution.

\separate{7}Suppose that \(\mathbf{x}^* \neq \mathbf{x}\). Then
\begin{itemize}
    \item \(x_i^* < x_i\) for some \(i \leq k+1\). 
    \item Let \(j = \min\{i:x_i^* < x_i\}\).
    \item And \(x_l^* > x_l\) for some \(l > j\).
\end{itemize}
Let us add some more of item \(j\) to the optimal choice. Let \(y\) be another solution, defined by 
\begin{equation}
    y = \begin{cases}y_j = \min\{w_j, x_j^* + (x_l^* - x_l)\}\\y_l = x_l^* - (y_j - x_j^*)\\y_i=x_i^* \text{   otherwise.}\end{cases}
\end{equation}
