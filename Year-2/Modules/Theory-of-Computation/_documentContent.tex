\subsection{Finite-State Automata and Regular Languages}

\subsubsection{Formal Definitions}

\definition{Deterministic Finite-State Automaton}{A \underline{deterministic finite-state automaton} is a five-tuple \((Q,\Sigma,\delta,q_0,F)\) where \(Q\) is the finite set of states, \(\Sigma\) is a finite alphabet, \(\delta: Q \times \Sigma \rightarrow Q\) is the transition function, \(q_0 \in Q\) is the start state, and \(F \subseteq Q\) is the set of accept states.}

\separate{7}\definition{Recognises}{A DFA \(M\) recognises the language \(L\) if \(L = \{w | M \text{ accepts } W\}\).}

\separate{7}\definition{Regular Languages}{A language is called a \underline{regular language} if some DFA recognises it.}

\separate{7}\definition{Regular Expression}{A \underline{regular expression} \(R\) defines a language \(L(R)\). We shall eventually prove that \(RE \equiv DFA\). \(R\) is a regular expression over the alphabet \(\Sigma\) if \(R\) is:
\begin{enumerate}
    \item \(a\) for some \(a \in \Sigma\).
    \item \(\epsilon\) (the empty string).
    \item \(\emptyset\) (the empty set).
    \item \((R_1 \cup R_2)\) where \(R_1\) and \(R_2\) are regular expressions.
    \item \(R_1 \cdot R_2\) where \(R_1\) and \(R_2\) are regular expressions.
    \item \(R_1^*\) where \(R_1\) is a regular expression.
\end{enumerate}
The list of regular operations can be seen in \elemref{tab:Regular Operations.}{Table} where the operations labelled with \(^+\) are language theory specific.}

\subsubsection{Combining Automata}

Sometimes we may want to implement an operation on multiple languages. We can do this by combining their automata. If we have that \(L_1\) is recognised by \(M_1 = (Q_1,\Sigma,\delta_1,q_1,F_1)\) and \(L_2\) is recognised by \(M_2 = (Q_2,\Sigma,\delta_2,q_2,F_2)\); we want to combine \(M_1\) and \(M_2\) into a new automaton \(M\) that would recognise \(L_1 \cup L_2\).

You would think that we could just run the automata sequentially, and accept if either \(M_1\) or \(M_2\) accept, but this does not work. This is because after \(M_1\) has run on the input, the input is exhausted and there is no way to rewind it in order to run \(M_2\).

Instead, we can attempt to run \(M_1\) and \(M_2\) on the input in parallel. We do this by using pairs of states (one for each DFA). Formally, the components of the new automaton \(M = (Q, \Sigma, \delta, q_0, F)\) are:
\begin{enumerate}
    \item The set of possible states contains every possible cross-set pair of \(Q_1\) and \(Q_2\).
    \[Q = Q_1 \times Q_2\] 
    \item For every \(s \in Q_1, u \in Q_2, a \in \Sigma\). The transition function contains every transition from a pair of states from \(Q\) being given any input from \(\Sigma\).
    \[\delta((s,u),a) = (\delta_1(s,a),\delta(u,a))\]
    \item The start state is the pair containing both start states from \(M_1\) and \(M_2\).
    \[q_0 = (q_1,q_2)\]
    \item The set of accept states is every possible cross-set pair of accept states from \(F_1\) and \(F_2\).
    \[F = \{(s,u) \in Q | s \in F_1 \text{ or } u \in F_2\}\]
\end{enumerate}

\subsubsection{Non-Deterministic Finite Automaton}

If, instead you wish to work with concatenation, such that \(w \in L_1 \circ L_2\) only if there are words \(x\) and \(y\) such that \(w=xy\), \(x \in L_1\) and \(y \in L_2\). You need to run \(M_1\) on a prefix of \(w\) and then run \(M_2\) on the rest. This must be done non-deterministically and stops becoming a DFA as all accept states of \(M_1\) have to map to the start state of \(M_2\).

\separate{7}\definition{Non-Deterministic Finite Automata}{A \underline{non-deterministic finite automaton} is a five-tuple \((Q,\Sigma,\delta,q_0,F)\), where \(Q\) is the finite set of states, \(\Sigma\) is a finite alphabet, \(\delta: Q \times (\Sigma \cup \{\epsilon\}) \rightarrow \mathscr{P}(Q)\) is the transition function, \(q_0 \in Q\) is the start state, and \(F \subseteq Q\) is the set of accept states.}

\subsubsection*{Computing NFA}

Before computing an NFA, an important convention to note is that a single step in a computation consists of first reading the next input symbol followed by taking any number of \(\epsilon\)-transitions. This means that empty strings \(\epsilon\)s can be freely added inside the actual word \(\in \Sigma*\), e.g., 010110 can be viewed as, say, \(\epsilon 01 \epsilon\epsilon 01 \epsilon 01\).

Let \(M = (Q,\Sigma,\delta,q_0,F)\) be an NFA and \(w=w_1w_2...w_n\) be a word over \(\Sigma \cup \{\epsilon\}\). \(M\) accepts \(w\) if there exists a sequence of states \(r_0,r_1,r_2,...,r_n\) satisfying the following conditions:
\begin{enumerate}
    \item \(r_0 = q_0\).
    \item \(r_{i+1} \in \delta(r_i,w_{i+1})\) for every \(i, 0 \leq i \leq n-1\).
    \item \(r_n \in F\).
\end{enumerate}

\subsubsection{Converting NFA into DFA}

The difference between a DFA and NFA is that a DFA has a unique computation (path) and either accepts or rejects, while an NFA generally has many computation paths and accepts if at least one computation accepts and only rejects if all the computations reject.

\separate{7}\theorem{nfa to dfa}{Every NFA has an equivalent DFA.}
{To formally convert an NFA to a DFA, let \(N = (Q, \Sigma, \delta, q_0, F)\) be an NFA recognising some language \(L\) (assume that \(N\) has no \(\epsilon\)-transitions). We shall construct a DFA \(M = (Q', \Sigma, \delta', q_0', F')\) that recognises the same language \(L\) as follows.
\begin{enumerate}
    \item \(Q' = \mathscr{P}(Q)\).
    \item For \(R \in Q'\) and \(a \in \Sigma\), let
    \begin{equation}\label{equation:step2a}
        \delta'(R,a) = \{q \in Q | q \in \delta(r,a) \text{ for some } r \in R\}
    \end{equation}
    equivalently,
    \begin{equation}\label{equation:step2b}
        \delta'(R,a) = \bigcup_{r \in R} \delta(r,a)
    \end{equation}
    \item \(q_0' = \{q_0\}\).
    \item \(F' = \{R \in Q' | \exists r \in R, r \in F\}\).
\end{enumerate}
Now, to consider \(\epsilon\)-transitions, for \(R \subseteq Q\), let 
\begin{equation}
    E(R) = \{q | q \text{ is reachable from } R \text{ through a number of } \epsilon \text{-transitions.}\}
\end{equation}
Now, taking the above steps, we modify \eqref{equation:step2a} to
\begin{equation}
    \delta'(R,a) = \{q \in Q | q \in E(\delta(r,a)) \text{ for some } r \in R\}
\end{equation}
and \eqref{equation:step2b} to
\begin{equation}
    \delta'(R,a) = \bigcup_{r \in R} E(\delta(r,a))
\end{equation}
We then modify step 3 to say \(q_0' = E(\{q_0\})\).}

\separate{7}\numberedentry{corollary regex nfa}{Corollary}{A language is regular iff some NFA recognises it.}
\proof{entry:corollary regex nfa}{See \postenvref{thm:nfa to dfa}{Theorem}{theoremnumber}.}

\separate{7}\theorem{regex expression recognition}{A language is regular iff some regular expression describes it.}
{\(\Leftarrow\) Given a regular expression \(R\), construct a NFA that recognises \(L(R)\) by structural induction:
\begin{itemize}
    \item \textit{Base Case}: All initial regular expressions can be implemented by NFAs.
    \item \textit{Inductive Step}: We have already proven that the class of regular languages is closed under regular operations.
\end{itemize}

\noindent \(\Rightarrow\) Given a DFA \(M\), construct a regular expression that recognises \(L(M)\).
\begin{enumerate}
    \item Convert the given \(n\)-state DFA into an equivalent \(n+2\) state GNFA.
    \item Eliminate all the internal states of the GNFA one-by-one, while preserving the language recognised by the automaton.
    \begin{enumerate}
        \item Pick an internal state \(r\) for elimination.
        \item For every two states \(u\) and \(v\) with transitions between them and \(r\), \(u \neq r, v \neq r\), combine the regular expressions of the three into one, new expression.
    \end{enumerate}
    \item \(L(R)\) should now equal \(L(M)\).
\end{enumerate}}

\separate{7}\definition{GNFA}{A \underline{generalised non-deterministic finite automaton} is defined as having a single start state with no incoming edges, a single end state with no outgoing edges, and every transition being labelled with a regular expression.}

\subsubsection{Non-Regular Expression}

\definition{Non-Regular Expressions}{A \underline{non-regular expression} is a language which cannot be recognised by any DFA. We prove a language is non-regular by assuming there is a DFA that recognises language \(L\) and then use an adversary argument against that DFA to get a contradiction.}

\separate{7}\lemma{Pumping Lemma}{The \underline{pumping lemma} states that, for every regular language \(L\), there is a number \(p\) (the pumping length of \(L\)) such that every word \(w \in L\) of length at least \(p\) can be divided into three parts \(w=xyz\), satisfying the following conditions:
\begin{enumerate}
    \item \(xy^iz \in L\) for every \(i \in N\) (in particular \(xz \in L\) as one can take \(i = 0\)).
    \item \(y\) is a non-empty string.
    \item The length of the string \(xy\) is not greater than \(p\).
\end{enumerate}}
{Let \(M = (Q, \Sigma, \delta, q_0, F)\) be a DFA that recognises \(L\), and let us set the pumping length \(p\) to be the number of states in \(M: p=|Q|\). Consider the computation of \(M\) on the word \(w=w_1w_2...w_n\) where \(n \geq p\).
\begin{equation}
    q_0 = r_0 \rightarrow w_1 \rightarrow r_1 \rightarrow w_2 \rightarrow ... r_{n-1} \rightarrow w_n \rightarrow r_n \in F
\end{equation}
Let \(i\) be the first moment in time when we see a repetition in the sequence of states \(r_0,r_1,...,r_n\) (such an \(i\) must exist by the Pigeon-Hole principle, as \(n+1 > p\)). i.e., \(r_i = r_j\) for some \(i > j\) and the states \(r_0,r_1,...,r_{i-1}\) are all different. We can then set
\begin{equation}
    x = w_1w_2...w_j \quad y = w_{j+1}...w_i \quad z = w_{i+1}...w_n
\end{equation}
It is now straightforward to check that all three conditions are met.}

\separate{7}\example{Pumping}{Prove that the language \(L = \{0^n1^n | n \in \N\}\) is not regular.

\separate{3}\proof{ex:Pumping}{Take the word \(0^p1^p \in L\) where \(p\) is the pumping length of \(L\).
If \(0^p1^p = xyz\) and \(|xy| \leq p\), then \(x=0^i, y=1^j\) and \(z=0^{p-i-j}1^p\).
But then \(xy^2z = 0^{p+j}1 \notin L\) as \(|y| > 0\), i.e., \(j > 0\).}}

\separate{7}\definition{DFA Minimisation}{An algorithm that \underline{minimises} any given DFA, i.e., finds an equivalent DFA with the minimal number of states.
It answers both \say{What is the smallest DFA that recognises the same language?} and \say{Given two DFAs, do they recognise the same language?}.
It can be achieved by removing any states not reachable from the start state and contracting a set of states that are equivalent into a single state.}

\separate{7}\definition{Equivalent States}{Two states \(s\) and \(t\) are \underline{equivalent} if any word \(w\), which is accepted when starting from \(s\), is also accepted when starting from \(t\).}

\separate{7}\definition{ETM}{A \underline{extended transition function} is defined by letting a DFA \(M = (Q,\Sigma,\delta,q_0,F)\) be given, and let \(\hat{\delta}: Q \times \Sigma^* \rightarrow Q\) be defined as:
\begin{equation}
    \hat{\delta}(s, \epsilon) = s
\end{equation}
\begin{equation}
    \hat{\delta}(s, w_1w_2...w_n) = \hat{\delta}(\delta(s,w_1),w_2,...,w_n)
\end{equation}
for every state \(s\) and every word \(w_1w_2...w_n\).}

\subsection{B{\"u}chi Automata and Omega-Regular Languages}

\subsubsection{Finite-State Automata Over Infinite Words}

\definition{Buchi Automata}{If we have a NFA where the input is infinite (i.e., \(\Sigma^\omega\)), we have a \underline{B{\"u}chi automaton}.}
A B{\"u}chi automaton accepts \(w_1w_2...\in \Sigma^\omega\) if there is a sequence of states \(r_0,r_1,r_2,...\in Q^\omega\) satisfying the following conditions:
\begin{itemize}
    \item \(r_0 = q_0\).
    \item \((r_i,w_{i+1},r_{i+1}) \in \Delta\) for every \(i > 0\).
    \item There are infinitely many \(r_i\)'s in \(F\).
\end{itemize}

\separate{7}\definition{Omega-Language}{An \underline{\(\omega\)-regular language/expression} is build upon regular languages, using the following operations:
\begin{itemize}
    \item \(A \cup B\), where both \(A\) and \(B\) are \(\omega\)-regular.
    \item \(AB\), where \(A\) is regular, and \(B\) is \(\omega\)-regular.
    \item \(A^\omega\), which is \(\{a_1...|a_i \in A\}\), i.e., an infinite sequence of words from \(A\), where \(A\) is regular and doesn't contain the empty word.
\end{itemize}}

\separate{7}Let \(A\) be a regular language. 
The limit of \(A\) is the language \(\{a \in \Sigma^\omega | a \text{ has infinitely many prefixes in } A\}\).

\separate{7}\(L_1 = \{a \in \Sigma^\omega | a \text{ contains infinitely many 0s.}\}\).
\\\(L_2 = \{a \in \Sigma^\omega | a \text{ contains finitely many 1s.}\}\).

\separate{7}\proposition{buchi_determinism}{\(L_2\) cannot be recognised by a deterministic B{\"u}chi automaton.}
{Assume that \(L_2\) can be recognised by some deterministic B{\"u}chi automaton \(M\).
We will construct a word accepted by \(M\) that contains infinitely many 1s and thus doesn't belong to \(L_2\).
\begin{enumerate}
    \item \(0^\omega \in L_2\) must be accepted by \(M\), so there is some finite prefix \(0^{n_1}\) that leads into accepting state \(p_1\).
    \item \(0^{n_1}10^\omega \in L_2\) must be accepted by \(M\), so there is some finite prefix \(0^{n_1}10^{n_2}\) that leads into accepting state \(p_2\).
    \item \(0^{n_1}10^{n_2}10^\omega \in L_2\) must be accepted by \(M\), so there is some finite prefix \(0^{n_1}10^{n_2}10^{n_3}\) that leads into accepting state \(p_3\).
    \item ...
\end{enumerate}
The limit of the infinite process is a word of the form \((0^*1)^\omega \notin L_2\) that is accepted by \(M\) since it visits an infinite sequence of accepting states \(p_1,p_2,...\).}

\subsubsection{Modal Logic}

\definition{Box Operator}{The \underline{box operator} is used with propositional logic \(\square\varphi\) to mean \say{I know/can prove} \(\varphi\).
More generally - necessarily \(\varphi\).
Probably \(\square\varphi \rightarrow \varphi\), but not the other way round (\(\varphi\) is true, but we may not be able to prove it).}

\separate{7}\definition{Diamond Operator}{The \underline{diamond operator} is used in \(\lnot \square \varphi \stackrel{\text{def}}{=} \diamond \lnot \varphi\) to indicate that you cannot prove \(\varphi\), so it is possible that \(\lnot \varphi\).
Conversely, \(\lnot \diamond \varphi\) (\(\varphi\) is impossible) is the same as proving \(\lnot \varphi\), i.e., \(\square \lnot \varphi\).
Simply, \(\diamond\) means \say{it is possible that}.}

\separate{7}From these definitions and propositional logic, we get:
\begin{itemize}
    \item \(\frac{\varphi}{\square \varphi}\) is the Neccesitation Rule \(\mathbf{N}\).
    \item \(\square(\varphi \rightarrow \psi) \rightarrow (\square \varphi \rightarrow \square \psi)\) is the Distribution Axiom \(\mathbf{K}\).
\end{itemize}

\separate{7}\definition{Kripke Semantics}{\underline{Kripke semantics} state that, over a set of atomic propositions (Boolean variables) \(P\), and a set of worlds (states) \(W\), we are given a valuation function
\begin{equation}
    f: P \times W \rightarrow \{true, false\}
\end{equation}
and an accessibilty relation
\begin{equation}
    R \subseteq W \times W
\end{equation}
\((u,v) \in R\) if \(v\) is accessible from \(u\).
\(\square a\) holds at \(u\) iff \(a\) holds at every \(v\), s.t. \((u,v) \in R\).
Thus, \(\diamond a\) holds at \(u\) iff \(a\) holds at some \(v\), s.t. \((u,v) \in R\).}

\subsection{Greedy Algorithms}

\definition{The Knapsack Problem}{\underline{The knapsack problem} is defined as one of two variants. Either:
\begin{itemize}
    \item The \underline{0-1 knapsack problem} (the classic variant), where a thief robs a store and finds \(n\) items. Item \(i\) is worth \(v_i\) euros and weighs \(w_i\) kilos. The thief can carry at most \(W\) kilos in his knapsack. \textit{Which items can he take to maximise his profit?}
    \item the \underline{fractional knap problem}, which has the same setup, but this time the thief can take fractions of items.
    \item We can assume (without loss of generality) that the knapsack is not big enough to carry all items:
    \begin{equation}
        W < w_1 + w_2 + ... + w_n
    \end{equation}
\end{itemize}}

\subsubsection{The Greedy Approach}

To solve the fractional problem, the greedy approach would be to calculate the value per kilo using \eqref{equ:knapsack_value} for each item. You then sort the items by value per kilo, in decreasing order. You then take as much of the first item as possible, then the second item, etc., until you reach the capacity of the knapsack \(W\).
\begin{equation}\label{equ:knapsack_value}
    r_i = \frac{v_i}{w_i}
\end{equation}


\separate{7}\example{Greedy knapsack}{For example, if \(W=10\), and \(\mathbf{v} = \{4, 10, 12, 20\}\) and \(\mathbf{w} = \{4, 2, 8, 5\}\). We can then calculate \(\mathbf{r} = \{1, 5, 1.5, 4\}\). The greedy algorithm then dictates that you should take all of item 2, all of item 4, and 3 kilos of item 3 \(W = 2 + 5 + 3\). This gives a total value of \(V = 10 + 20 + (3 \times 1.5) = 34.5\).}

\separate{7}The running time of this algorithm can be calculated by taking that:
\begin{enumerate}
    \item Step 1, calculating the value per kilo takes \(\Theta (n)\).
    \item Step 2, sorting the value per kilo array takes \(\Theta (n\;log\;n)\).
    \item Step 3, selecting the items can be done in \(\Theta (n)\).
\end{enumerate}
Therefore, the worst-case running time is \(\Theta (n\;log\;n)\).

\separate{7}However, approach will not work for the 0-1 knapsack problem.

\subsubsection{Correctness of the Greedy Algorithm for Fractional Knapsack}

\(n\) items are sorted by value per kilo, \eqref{equ:knapsack_value} in decreasing order, i.e., 
\begin{equation}
    r_1 \geq r_2 \geq ... \geq r_n
\end{equation}
Two items, \(p\) and \(q\) with \(r_p = r_q\) are considered to be equivalent. Hence, we may assume that
\begin{equation}
    r_1 > r_2 > ... > r_n
\end{equation}
The total available amount of item \(i\) is \(w_i\). Let \(k\) be such that
\begin{equation}
    w_1 + w_2 + ... + w_k \leq W
\end{equation}
and
\begin{equation}
    w_1 + w_2 + ... + w_{k+1} > W
\end{equation}
Let \(\mathbf{x} = (x_1, x_2, ..., x_n)\) denote a solution: \(0 \leq x_i \leq w_i\) is the amount the thief takes of item \(i\) for \(i = [0, n]\). The total value taken is then given by
\begin{equation}
    \sum_{i=1}^{n} r_ix_i
\end{equation}
The greedy solution \(\mathbf{x}\) is given by \(x_i = w_i\) for \(1 \leq i \leq k\) and 
\begin{equation}
    x_{k+1} = W - (w_1 + w_2 + ... + w_k)
\end{equation}
\(x_i = 0\) for \(k+2 \leq i \leq n\). Let \(\mathbf{x}^* = (x_1^*, x_2^*, ..., x_n^*)\) be an optimal solution.

\separate{7}Suppose that \(\mathbf{x}^* \neq \mathbf{x}\). Then
\begin{itemize}
    \item \(x_i^* < x_i\) for some \(i \leq k+1\). 
    \item Let \(j = \min\{i:x_i^* < x_i\}\).
    \item And \(x_l^* > x_l\) for some \(l > j\).
\end{itemize}
Let us add some more of item \(j\) to the optimal choice. Let \(y\) be another solution, defined by 
\begin{equation}
    y = \begin{cases}y_j = \min\{w_j, x_j^* + (x_l^* - x_l)\}\\y_l = x_l^* - (y_j - x_j^*)\\y_i=x_i^* \text{   otherwise.}\end{cases}
\end{equation}

\subsection{Divide-and-Conquer Algorithms}

\subsubsection{Colouring for Restricted Inputs}

\definition{DaC Algorithms}{Many useful algorithms utilise recursions to quickly resolve subproblems. 
We refer to these as \underline{divide-and-conquer algorithms}, as at each step they:
\begin{enumerate}
    \item \textit{Divide} the problem into a number of subproblems.
    \item \textit{Conquer} the subproblems by solving them, either recursively or directly depending on size.
    \item \textit{Combine} the solutions for the subproblems into a solution for the original problem.
\end{enumerate}
A natural way to calculate the running time of these algorithms is recurrence relations using the Master Theorem (covered in Year 1 - Algorithms and Data Structures).}

\separate{7}\definition{Colouring}{A \underline{colouring} of a graph is an assignment of colours to its vertices such that any two adjacent vertices get a different colour. 
A colouring using at most \(k\) colours is a \underline{\(k\)-colouring}.}

\separate{7}\definition{Chromatic Number}{The \underline{chromatic number}, \(\chi_G\), of a graph is the smallest integer \(k\) for which \(G\) has a \(k\)-colouring.
Calculating the chromatic number of any given graph is considered a NP-hard problem.}

\separate{7}\definition{Disjoint Union}{Let \(G_1\) and \(G_2\) be two vertex-disjoint graphs.
The \underline{disjoint union} \(G_1+G_2\) is the graph with vertex set \(V(G_1) \cup V(G_2)\) and edge set \(E(G_1) \cup E(G_2)\).}

\separate{7}\definition{Join}{Let \(G_1\) and \(G_2\) be two vertex-disjoint graphs.
The \underline{join} \(G_1 \times G_2\) is the graph with vertex set \(V(G_1) \cup V(G_2)\) and edge set \(E(G_1) \cup E(G_2) \cup E^*\), where \(E^*\) is the set of all edges between vertices of \(G_1\) and vertices of \(G_2\).}

\separate{7}\definition{Cograph}{Let \(G_1\) and \(G_2\) be two vertex-disjoint graphs.
A graph \(G\) is a \underline{cograph} if it can be created using the following rules:
\begin{itemize}
    \item The 1-vertex graph is a cograph.
    \item If \(G_1\) and \(G_2\) are cographs, then so is \(G_1 + G_2\).
    \item If \(G_1\) and \(G_2\) are cographs, then so is \(G_1 \times G_2\).
\end{itemize}
Alternatively, let \(P_4\) denote the path on 4 vertices. 
A graph \(G\) contains \(P_4\) as an \underline{induced subgraph} if \(G\) can be modified to \(P_4\) via vertex deletions.
If not, then \(G\) is said to be \underline{\(P_4\)-free}.}

\separate{7}\theorem{Cographs}{A graph \(G\) is a cograph \(\iff\) \(G\) is \(P_4\)-free.}
{Proof excluded.}

\separate{7}\definition{Cotree}{Let \(G\) be a cograph. 
The \underline{cotree} \(T_G\) of \(G\) is the unique decomposition tree that satisfies:
\begin{enumerate}
    \item The root \(r\) of the tree represents the graph \(G_r = G\).
    \item Every leaf \(x\) of the tree represents exactly one vertex of \(G\), and vice-versa.
    \item Every internal node \(x\) of the tree has at least two children and is either labelled \(+\) or \(\times\). 
        The node represents an induced subgraph \(G_x\) of \(G\), defined as follows:
        \begin{itemize}
            \item If \(x\) is a \(+\)-node, then \(G_x\) is the disjoint union of all graphs \(G_y\) where \(y\) is a child of \(x\).
            \item If \(x\) is a \(\times\)-node, then \(G_x\) is the join of all graphs \(G_y\) where \(y\) is a child of \(x\).
        \end{itemize}  
    \item Along the path from the root \(r\) to any leaf, the labels of the internal notes alternate between \(+\) and \(\times\).
\end{enumerate}}

\separate{7}\theorem{Cotrees}{Any cograph \(G\) has a unique cotree.
However, if we drop condition 4, there may be many trees representing \(G\).}
{Proof excluded.}

\separate{7}We can use a divide-and-conquer algorithm to colour a cograph. 
Given a cograph \(G\), construct its cotree \(T_G\). 
This can be done in \(O(n+m)\) time \hyperref[cit:A Linear Recognition Algorithm for Cographs]{(Corneil, Perl and Stewart, 1985)}. 
We follow a bottom-up approach: only process node \(x\) after first processing its children.
\begin{itemize}
    \item \textit{Leaves}: Each leaf represents a single vertex of \(G\).
        The chromatic number of a single-vertex graph is 1.
    \item \textit{Union-Nodes}: If \(x\) is a \(+\)-node, then \(\chi_{G_x}\) is the maximum of the chromatic numbers of the graphs \(G_y\), where \(y\) is a child of \(x\).
    \item \textit{Join-Nodes}: If \(x\) is a \(\times\)-node, then \(\chi_{G_x}\) is the sum of the chromatic numbers of the graphs \(G_y\), where \(y\) is a child of \(x\).
\end{itemize}
This way, the last node we process is the root \(r\), which represents the graph \(G_r=G\).
As the number of nodes of \(T\) is \(O(n)\) and we used \(O(n)\) time per node, the total running time is polynomial.

\begin{algorithm}[H]
    \caption{MAX-SUBARR}
    \begin{algorithmic}
        \State \textbf{Input}: \(A\), low, high
        \State \textbf{Output}: low, high, sum
        
        \separate{7}
        \If{high = low}
            \Return (low, high, \(A\)[low])
        \Else
            \State median \(\gets \left\lfloor \frac{\text{low} + \text{high}}{2} \right\rfloor\)
            \State \((L_{low}, L_{high}, L_{sum}) \gets\) MAX-SUBARR(\(A\), low, median) 
            \State \((R_{low}, R_{high}, R_{sum}) \gets\) MAX-SUBARR(\(A\), median\(+1\), high) 
            \State \((\text{Cross}_{low}, \text{Cross}_{high}, \text{Cross}_{sum}) \gets\) MAX-CROSS-SUBARR(\(A\), low, median, high) 

            \If{\(L_{sum} \geq \max\{R_{sum}, \text{Cross}_{sum}\}\)}
                \Return \((L_{low}, L_{high}, L_{sum})\)
            \EndIf
            \If{\(R_{sum} \geq \max\{L_{sum}, \text{Cross}_{sum}\}\)}
                \Return \((R_{low}, R_{high}, R_{sum})\)
            \Else \( \) \Return \((\text{Cross}_{low}, \text{Cross}_{high}, \text{Cross}_{sum})\)
            \EndIf
        \EndIf
    \end{algorithmic}
    \label{alg:maxsumarr}
\end{algorithm}

\begin{algorithm}[H]
    \caption{MAX-CROSS-SUBARR}
    \begin{algorithmic}
        \State \textbf{Input}: \(A\), low, mid, high
        \State \textbf{Output}: max\_left, max\_right, left\_sum\(+\)right\_sum
        
        \separate{7}
        \State left\_sum\(\gets -\infty\)
        \For{\(i \gets\)\text{mid} to low}
            \State sum \(\gets\) sum\(+ A[i]\)
            \If{sum \(>\) left\_sum}
                \State left\_sum \(\gets\) sum
                \State max\_left \(\gets i\)
            \EndIf
        \EndFor

        \For{\(j \gets\)\text{mid}\(+1\) to high}
            \State sum \(\gets\) sum\(+ A[j]\)
            \If{sum \(>\) right\_sum}
                \State right\_sum \(\gets\) sum
                \State max\_right \(\gets j\)
            \EndIf
        \EndFor

        \noindent\Return (max\_left, max\_right, left\_sum\(+\)right\_sum)
    \end{algorithmic}
    \label{alg:maxcrosssubarr}
\end{algorithm}

\subsubsection{The Master Theorem}

\definition{Master Theorem}{The \underline{master theorem} is formally defined as follows:\\
Let \(T(n)\) be a function on the natural numbers defined by
\begin{equation}
    T(n) = aT \left(\frac{n}{b}\right) + f(n)
\end{equation}
for some constants \(a \geq 1\) and \(b > 1\).
Then:
\begin{enumerate}
    \item If \(f(n) = O \left(n^{\log_b a-\epsilon}\right)\) for some constant \(\epsilon > 0\), then \(T(n) = \Theta \left(n^{\log_b a}\right)\).
    \item If \(f(n) = \Theta \left(n^{\log_b a}\right)\), then \(T(n) = \Theta \left(n^{\log_b a} \cdot \log n \right)\).
    \item If \(f(n) = \Omega \left(n^{\log_b a+\epsilon}\right)\) for some constant \(\epsilon > 0\), and if \(a \cdot f \left(\frac{n}{b}\right) \leq cf(n)\) for some constant \(c < 1\) and for sufficiently large \(n\), then \(T(n) = \Theta (f(n))\).
\end{enumerate}}

\separate{7}When multiplying two matrices, \(A,B \in \R^{n \times n}\) with output \(C \in \R^{n \times n}\), we can normally complete the computation in time \(\Theta \left(n^3\right)\) by using the following definition:
\begin{equation}
    c_{ij} = \sum_{k=1}^{n} a_{ik} b_{kj}
\end{equation}
However, we can design a divide-and-conquer algorithm to do this much quicker using \hyperref[alg:mult]{MULT(A,B)}.
The running time of MULT(\(A,B\)) satisfies
\begin{equation}
    T(n) = 8 T \left(\frac{n}{2}\right) + \Theta \left(n^2\right)
\end{equation}
since we have 8 multiplications of \(\frac{n}{2} \times \frac{n}{2}\) matrices and 4 matrix additions, each taking time \(\Theta \left(\frac{n}{2} \cdot \frac{n}{2}\right) = \Theta\left(n^2\right)\).
Therefore, the master theorem implies that \(T(n) = \Theta \left(n^3\right)\).

\begin{algorithm}[H]
    \caption{MULT(A,B)}
    \begin{algorithmic}
        \State \textbf{Input}: \(A,B \in \R^{n \times n}\)
        \State \textbf{Output}: \(C \in \R^{n \times n}\)
        
        \separate{7}
        \State Let \(C\) be a new \(n \times n\) matrix.

        \If{\(n = 1\)}
            \State \(c_{1,1} \gets a_{1,1}b_{1,1}\)
        \Else
            \State Partition \(A,B,C\) into the block matrices.
            \State \(C_{1,1} \gets \text{MULT}(A_{1,1}, B_{1,1}) + \text{MULT}(A_{1,2}, B_{2,1})\)
            \State \(C_{1,2} \gets \text{MULT}(A_{1,1}, B_{1,2}) + \text{MULT}(A_{1,2}, B_{2,2})\)
            \State \(C_{2,1} \gets \text{MULT}(A_{2,1}, B_{1,1}) + \text{MULT}(A_{2,2}, B_{2,1})\)
            \State \(C_{2,2} \gets \text{MULT}(A_{2,1}, B_{1,2}) + \text{MULT}(A_{2,2}, B_{2,2})\)
        \EndIf

        \noindent\Return \(C\)
    \end{algorithmic}
    \label{alg:mult}
\end{algorithm}

\subsubsection{Strassen's Algorithm}

\definition{Strassen's Algorithm}{Strassen (1969) made a sophisticated divide-and-conquer approach called \underline{Strassen's} \underline{algorithm}.
It has four steps:
\begin{enumerate}
    \item Divide \(A,B\), and \(C\) into four parts as before, with running time \(\Theta(1)\).
    \item Create 10 auxiliary matrices \(S_1,...,S_10 \in \R^{\frac{n}{2} \times \frac{n}{2}}\), obtained by sums or differences of \(A_{1,1},...,B_{2,2}\), with running time \(\Theta \left(n^2\right)\).
    \item Using all the matrices available, recursively compute seven product matrices \(P_1,...,P_7 \in \R^{\frac{n}{2} \times \frac{n}{2}}\), with running time \(7 T \left(\frac{n}{2}\right)\).
    \item Compute \(C_{1,1},...,C_{2,2}\) by adding/subtracting combinations of \(P_1,...,P_7\), with running time \(\Theta \left(n^2\right)\).
\end{enumerate}
Thus, the worst-case running time of Strassen's algorithm satisfies
\begin{equation}
    T(n) \leq 7 T \left( \frac{n}{2} \right) + \Theta \left( n^2 \right)
\end{equation}
so, by the master theorem, we obtain
\begin{equation}
    T(n) = \Theta \left( n^{log_2 7} \right) = \Theta \left( n^{2.8074} \right)
\end{equation}}

\subsubsection{Rod Cutting}

\definition{Rod Cutting Problem}{The \underline{rod cutting problem} states that you work for a company that buys steel rods and cuts them into shorter rods, which it then sells.
You are asked to determine the best way to cut the rods so as to maximise profit. 
You know, for \(i=1,...,n\), the price \(p_i\) in euros that the company charges for a rod of length \(i\) centimeters.
Given a rod of length \(n\) and a table of prices \(p_i\) for \(i=1,...,n\), determine the maximum revenue \(r_n\) obtained by cutting up the rod and selling the pieces.}

\separate{7}\definition{Partition}{An \underline{integer partition} of a positive integer \(n\) is a list of positive integers \((a_1,...,a_k)\) such that \(a_1 \leq ... \leq a_k\) and
\begin{equation}
    \sum_{i=1}^k a_i = n
\end{equation}
Let \(p(n)\) denote the number of integer partitions of \(n\), then
\begin{equation}
    p(1) = 1, p(2) = 2, p(3) = 3, p(4) = 5
\end{equation}
Hardy and Ramanujan proved that 
\begin{equation}
    p(n) \sim \frac{1}{4n\sqrt{3}} \exp \left( \pi \sqrt{\frac{2n}{3}} \right)
\end{equation}
Therefore, brute force has an exponential running time.}

\separate{7}\definition{Optimal Substructure}{\underline{Optimal Substructure}: Optimal solutions to a problem incorporate optimal solutions to related subproblems, which we may solve independently.}

\separate{7}More specifically, for the rod cutting problem, we have for all \(n \geq 1\),
\begin{equation}
    r_n = \max \{p_i + r_{n-i}: 1 \leq i \leq n\}
\end{equation}
The idea behind this is that \(p_n\) corresponds to no cuts and \(p_i + p_{n-i}\) to cutting into a rod of length \(i\) and another rod of length \(n-i\).
To solve the original problem of size \(n\), we solve independent smaller problems of the same type, but of smaller sizes. 
For the rod problem, we can use the following algorithm:

\begin{algorithm}[H]
    \caption{ROD(\(p,n\))}
    \begin{algorithmic}
        \State \textbf{Input}: \(p,n\)
        \State \textbf{Output}: \(q\)
        
        \separate{7}
        \If{\(n = 0\)}
            \Return 0
        \EndIf

        \State \(q \gets -1\)
        
        \For{\(i \gets 1\) to \(n\)}
            \State \(q \gets \max \{q,p[i] + ROD(p,n-i)\}\)
        \EndFor

        \noindent\Return \(q\)
    \end{algorithmic}
    \label{alg:rod}
\end{algorithm}
